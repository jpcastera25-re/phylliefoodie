# Phyllie’s Foodie’s

A simple, static one-page bakery landing page for **Phyllie’s Foodie’s**, a warm home-style bread-focused bakery concept by Phyllis.

## What is included

- Cozy hero section with scroll CTAs
- Featured quickbreaks / breads menu
- “Jams Coming Soon” teaser
- Personal “About Phyllie” section
- Placeholder contact buttons that are easy to replace later
- Responsive, static HTML and CSS only

## Run locally

Open `index.html` directly in a browser, or serve the folder with a static server:

```bash
python3 -m http.server 4173
```

Then visit <http://localhost:4173>.
